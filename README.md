# DM_DUEL v3 — дуэль снайперов

Аркадный снайперский шутер в браузере: честная баллистика, паркур, три типа боеприпаса
с разным характером и мультиплеер на четверых. Стиль — Team Fortress 2 с лёгкой магией.

**Ни установки, ни сборки, ни зависимостей.** Игра — один самодостаточный HTML-файл:
скачал, открыл в браузере, играешь.

## Быстрый старт

### Просто поиграть одному

1. Скачайте [`dm_duel_v3.html`](dm_duel_v3.html).
2. Откройте двойным щелчком в браузере.
3. Нажмите **В БОЙ**.

Всё. Ни Node, ни сервера, ни установки не нужно.

> **Нужен интернет при первом запуске.** Движок three.js подгружается с CDN. Если открыть
> файл без сети, вы увидите сообщение об этом на весь экран.

> Рядом лежит [`dm_duel_v2.html`](dm_duel_v2.html) — исходная версия игры, с которой всё
> начиналось: без паркура, мультиплеера и трёхъярусной карты. Оставлена для сравнения,
> играть стоит в v3.

## Игра с друзьями

До **4 игроков** в командах BLU и RED, свободные слоты добивают боты. Сервер нужен только
одному из вас — тому, кто «поднимает комнату».

### Шаг 1. Поднять сервер

Нужен [Node.js 18+](https://nodejs.org) (проверено на 22). В папке проекта:

```bash
node net/server.js
```

Сервер напечатает готовые адреса — свой и все адреса вашей машины в локальной сети:

```
  DM_DUEL v3 · сервер комнаты
  ────────────────────────────────────────────────
  игроков до 4, слотов 8 (остальное — боты), до 20 убийств, тик 20 Гц

  на этой машине:
    http://localhost:8177/

  друзьям в локальной сети:
    http://192.168.1.12:8177/    (Беспроводная сеть)
```

Сервер сам раздаёт и саму игру, так что отдельно ничего открывать не надо.

### Шаг 2. Подключиться

**Вы (хозяин комнаты):** откройте `http://localhost:8177/`.

**Друзья в той же сети (дома, в общежитии, на работе):** открывают ваш адрес вида
`http://192.168.1.12:8177/` — тот, что напечатал сервер.

Дальше все нажимают **ИГРАТЬ ПО СЕТИ**: адрес уже подставлен, остаётся ввести имя.

### Шаг 3. Играть через интернет

Если друзья не в вашей сети, нужен туннель — он даёт публичный адрес без проброса портов
и настройки роутера. Любой на выбор:

```bash
cloudflared tunnel --url http://localhost:8177
```

```bash
ngrok http 8177
```

Туннель напечатает адрес вида `https://something-random.trycloudflare.com`. Раздайте его
друзьям — они открывают его в браузере, и всё работает так же.

### Другой порт

```bash
node net/server.js --port 9000
```

### Проверить состояние комнаты

`http://localhost:8177/__status` — кто подключён, счёт, пинги, сколько ботов.

### Как устроена честность

Попадание засчитывает **стреляющий**: вы бьёте по тому, что видите у себя на экране.
В игре, где пуля летит до полусекунды, это единственный способ избавиться от «я же попал».

Сервер владеет **здоровьем, очками, смертями и пикапами** и проверяет каждую заявку:
жив ли стрелок, соблюдён ли темп затвора, не пробит ли потолок урона для типа боеприпаса,
исходит ли выстрел из вашей позиции и смотрит ли в цель, стоите ли вы рядом с аптечкой.

Этого достаточно, чтобы ничего не разъезжалось и никто не жульничал по мелочи.
**Но это не защита от подготовленного читера** — игра рассчитана на компанию друзей.

## Боеприпасы

От выбора патрона зависит характер стрельбы. У каждого типа **свой откат**, который тикает
всегда — даже когда выбран другой тип.

| | Матчевый | Фугасный | Зажигательный |
|---|---|---|---|
| **Откат** | нет | 2.5 с | **5 с** |
| **Крит в голову** | полный | **нет вообще** | ×2.2 |
| **Прямой урон** | 34 → 90 | 20 → 44 | 18 → 38 |
| **Особое** | эталонная баллистика | урон по радиусу 5.2 м | горение 11/с × 6 с |
| **Зачем** | размен один в один | выкурить из укрытия | контроль территории |

**Фугасный** бьёт площадью: максимум в эпицентре, дальше урон падает, за укрытием режется
примерно вдвое, но не в ноль — именно поэтому им выкуривают с точки, а не убивают с одного.
Пуля тяжёлая и заметно проседает — берите выше.

**Зажигательный** почти не бьёт напрямую, зато цель горит и теряет здоровье, даже уйдя за угол.
Промах оставляет очаг огня, который перекрывает подход или лестницу. Откат самый длинный:
пять секунд слот в поясе закрыт.

## Что внутри

- **Карта на три яруса**: 69 огневых позиций, 34 зоны лазания, 4 навесных мостика, 4 троса.
  В центре — магические руины с обелиском и парящими кристаллами.
- **Паркур**: подкат с разгона, магический рывок, доп. прыжок, подтягивание на уступ,
  coyote-time и буфер прыжка, лестницы и зиплайны.
- **Умные боты**: лазают по лестницам на верхние ярусы, обходят с флангов, окружают,
  ведут подавляющий огонь, срываются с позиции, когда горят.
- **Динамическое освещение**: жаровни, кристаллы, руны, очаги огня, вспышки выстрелов
  и взрывов — пул из 8 источников, переназначаемых по важности.
- **Процедурные текстуры**: 11 видов, всё рисуется кодом, ни одного внешнего файла.
- **Честная баллистика**: время полёта, падение пули, боковой ветер, дальномер и сетка
  с метками дальности в оптике.

## Сборка из исходников

Игра собирается из модулей `src/*` в один HTML-файл:

```bash
node build.js
```

Получится `dm_duel_v3.html`. Сборка заодно проверяет синтаксис склеенного скрипта и ищет
имена, объявленные в двух модулях сразу.

### Как это устроено

Все модули склеиваются **в один `<script>` и одну область видимости** в порядке имён файлов.
Поэтому объявление верхнего уровня в одном модуле видно всем остальным — это и есть «экспорт».

| Модуль | Отвечает за |
|---|---|
| `00_head.html`, `01_body.html` | разметка и стили HUD, экраны |
| `10_core.js` | конфиг, боекомплект, сложность, утилиты, звук |
| `20_render.js`, `22_tex.js` | рендер, свет, материалы, процедурные текстуры |
| `25_terrain.js` | рельеф, небо, атмосфера |
| `30_physics.js` | коллизии, лазание, паркурные примитивы |
| `40_props.js`, `45_map.js` | пропы и компоновка карты |
| `50_models.js` | модели винтовки и бойцов |
| `55_fx.js` | частицы, взрывы, огонь, магия |
| `60_weapon.js`, `87_weapon_update.js` | оружие, баллистика, боеприпасы |
| `70_ai.js` | ИИ противника и командный слой |
| `75_combat.js` | урон игроку, горение, пикапы |
| `80_hud.js` | обновление интерфейса |
| `85_player.js` | движение игрока и камера |
| `90_game.js` | ввод, состояния, главный цикл |
| `92_net.js`, `94_netplayers.js`, `96_netui.js` | сеть: транспорт, удалённые игроки, лобби |
| `98_boot.js` | запуск |

Правила, по которым живут модули, описаны в [CONTRACT.md](CONTRACT.md), протокол
мультиплеера — в [NETCONTRACT.md](NETCONTRACT.md), устройство сервера — в
[net/README.md](net/README.md).

## Проверки

**Приёмочный прогон одиночной игры** — проверяет публичный API, состояние мира, баланс
боеприпасов, откаты, отсутствие утечек:

```bash
node tools/serve.js
```

Откройте `http://localhost:8177/`, затем в консоли браузера:

```js
(function(){var x=new XMLHttpRequest();x.open('GET','/tools/smoke.js',false);x.send();return eval(x.responseText);})()
```

**Сквозной тест мультиплеера** — поднимает настоящий сервер, подключает живых клиентов
и проверяет комнату целиком: команды, снапшоты, урон, спор за пикап, убийство, респавн,
ботов, переизбрание хоста и устойчивость к мусору:

```bash
node tools/mptest.js
```
